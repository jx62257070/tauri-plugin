# 自选盯盘（dsh-sidebar-watch）

安装包文件名：`dsh-sidebar-watch-1.3.0.zip`

一句话：顶栏常驻一个**盯盘入口** —— 收起态是一条轮播（逐条滚动候选的名称 / 现价 / 涨跌幅），点开是完整清单。盯盘要的是「一眼扫到」，不长期占侧栏版面。

## 功能特性

- **顶栏常驻入口**：挂在应用顶栏右侧，收起态轮播候选，点开是完整清单。
- **逐只加入候选**：在自选股表格的「操作」列点「盯盘」，这只票就进候选池；再点一次即移出。
- **到价 / 涨跌幅提醒**：候选行右侧的铃铛点开阈值编辑器，价格（涨到 / 跌到）或涨跌幅（涨幅达到 / 跌幅达到）二选一，数值为正、方向由按钮表达；到价时右下角弹浮窗，点浮窗直接看这只票。
- **防抖动设计**：同一只票只占一格（反复触发是替换而不是刷屏），触发过一次后要等价格回到阈值内侧并越过**回差**才重新武装。
- **候选池可被复用**：提供 `watch:repo` 服务，其他插件可读写同一份候选池。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**。

1. 打开应用，进入「插件工坊」（应用内的插件管理入口）；
2. 选择「导入插件」，选中 `dsh-sidebar-watch-1.3.0.zip`；
3. 导入后启用，顶栏会出现盯盘入口。

卸载：在「插件工坊」里对该插件点卸载，应用会询问是否一并删除本地数据表。

## 快速上手

1. 打开自选股页，在「操作」列点「盯盘」，这只票就进候选池；
2. 点候选行右侧的铃铛设置阈值：先选类型（价格 / 涨跌幅），再选方向（涨到 / 跌到），填数值；数值填正数，方向由按钮表达；
3. 阈值到达时右下角弹浮窗，点浮窗直接看这只票；
4. 点候选行跳个股详情整页，左侧来源列表 = 全部盯盘候选，可一键切换同批股票；
5. 第一次打开时清单为空 —— 空态提示会告诉你候选从哪里来。

## 数据与隐私

- **数据来源**：报价走 WHF 股票看板提供的行情服务（`app:quotes`），轮询统一由应用的轮询调度器（`app:polling`）驱动，全插件只有这一处报价请求。
- **联网时机**：仅在应用设定的交易窗口内、由应用的轮询调度器按固定间隔取报价；候选池新增未取过价的标的时会先补拉一轮。
- **本地存储**：候选与阈值落在插件的独立本地数据表 `plugin_dsh_sidebar_watch_watch_candidates`（桌面端 SQLite / 浏览器端本地仿真），插件永不直接写 SQL；阈值规则与「已触发」状态同表落地，重启后仍保留。
- **卸载影响**：卸载时应用会询问是否一并删除数据表；**插件 id 一个字都不能改** —— 改了就等于换了一批新表，候选与阈值全部失联。

## 与其他插件的互操作

| 类型 | 名称 | 语义 |
| --- | --- | --- |
| 服务 | `watch:repo` | 其他插件 `ctx.consume('watch:repo')` 即可读写同一份候选池 |

## 已知限制

- **监控范围**：候选池 ∩ 当前自选股。把票从自选股移出，该行与它的告警一起停下，但候选记录与阈值仍保留 —— 重新加回自选股即自动续上。
- **阈值二选一**：一只票同一时刻只能有一种阈值类型（价格或涨跌幅），不能两者并存。
- **提醒防抖动**：同类型提醒「只占一格」，触发后需价格越过回差才重新武装，因此不会对每一次越界都弹提醒。
- **插件 id 的历史遗留**：入口已从侧栏搬到顶栏，但 id 仍为 `dsh-sidebar-watch`（名字里的 sidebar 已过时）。此为**故意不改** —— id 是数据表名与存储命名空间的一部分，改 id 等于让已积累的候选与阈值一夜清空。

## 设计说明

**为什么「没在看的时候也在盯」？** 盯盘引擎（取报价 → 判阈值 → 弹提醒）跑在**插件层**，不在面板组件里：顶栏下拉一收起，应用会把面板组件整个卸载，如果引擎挂在组件上，告警就会随下拉一起停摆 —— 而那正好是盯盘最没用的时候。引擎生命周期挂在插件上，卸载插件时才停轮询并清掉自己弹过的浮窗。

**为什么轮询不自己实现？** 轮询用的是应用的轮询调度器（交易窗口 / 失败退避 / 页面可见性等多份策略只有一份实现），全插件只有这一处报价请求，避免重复取数触碰上游频率红线。
