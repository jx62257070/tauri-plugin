# 股票主线（dsh-mainline）

安装包文件名：`dsh-mainline-1.0.0.zip`

一句话：把「板块抱团主线」从主观感觉变成**状态判定** —— 左侧导航新增「股票主线」看板，算出板块的成交占比分位、量能倍数、价格分位，映射到**一线四阶段**（萌芽 → 确认 → 狂热 → 瓦解），并同时展示原始指标面板与风险提示。

## 功能特性

- **四阶段状态判定**：对同花顺行业板块计算成交占比分位 / 量能倍数 / 价格分位，映射到萌芽、确认、狂热、瓦解四种阶段状态。
- **原始指标与标签同屏**：原始指标面板与自动标签同时展示，判断依据可见，不是黑箱打分。
- **未接入输入如实列出**：本期拿不到的数据（如公募持仓分位、北向环比）会在页面单独列出，缺什么明说。
- **阶段徽标即筛选**：点阶段徽标可按阶段多选筛选，快速聚焦某类板块。
- **数据本地留存**：扫描结果落本地表，再进页面只读本地快照重算，不联网。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**。

1. 打开应用，进入「插件工坊」（应用内的插件管理入口）；
2. 选择「导入插件」，选中 `dsh-mainline-1.0.0.zip`；
3. 导入后启用，左侧导航会出现「股票主线」。

卸载：在「插件工坊」里对该插件点卸载，应用会询问是否一并删除本地数据表。

## 快速上手

1. 首次进入看板是一片空 —— 扫描属重接口，**只在你点击时触发**，不做自动轮询；
2. 点「扫描主线」后开始逐板块取数并落本地表；扫描期间可看到进度（已请求数 / 板块总数）；
3. 之后再进页面**只读本地表重算，不联网**，秒开；
4. 想更新数据，再点一次「扫描主线」即可；
5. 点表格行可展开指标明细（数据截止、基准交易日、数据源、各项分位与量能等）。

## 数据与隐私

- **数据来源**：板块日线与成交额**优先同花顺**（行业板块清单页 + 板块日 K / 近端 K），仅在确认同花顺整体不可用时**整表降级**为东方财富（板块日 K + 板块快照）；沪深两市成交额走 WHF 股票看板的市场服务（腾讯日 K）；板块内涨停家数 / 最高连板 / 封板资金来自东财涨停池。
- **联网时机**：仅在你点击「扫描主线」时请求上游，不做自动轮询。
- **本地存储**：结构化数据落在插件的两张本地数据表 `plugin_dsh_mainline_board_history`（每板块每数据源一行，日线序列整体存 JSON 列）与 `plugin_dsh_mainline_scan_meta`（扫描元信息、沪深成交额序列、板块清单缓存）。
- **卸载影响**：卸载时应用会询问是否一并删除这两张表；**插件 id 一个字都不能改** —— 改了就等于换了一批新表，历史扫描结果全部失联。

## 已知限制

- **定位声明**：只输出阶段标签与风险提示，**不含任何买卖或仓位指令**，是概率工具而非预言。
- **「确认」的边界**：只有价格上涨、没有业绩验证不判「确认抱团」——「确认」仅代表量价与拥挤度特征，风险提示里明写「需连续两季业绩验证」。
- **口径**：成交占比 = 行业板块成交额 ÷ 沪深两市总成交额；同花顺口径下板块合计约为全市场成交额的 98.5%，存在约 1.5% 的系统性低估，但分位是同一基准下的相对位置，不受该缺口影响。
- **数据时效**：全部指标取「最近完整交易日」截面，盘中扫描不写入当日半日数据，避免污染占比分位序列。
- **数据源切换**：同花顺与东财两套板块指数不同源，点位不可比、成分不保证一致；两个来源的序列在本地**分开存放、永不拼接**，东财模式下部分板块可能找不到同义板块并如实标注为「无数据」。
- **样本累积**：分位序列靠自己累积，历史样本不足时判定层会**如实降置信度**（不猜结论）。

## 设计说明

**为什么不直接给「买 / 卖」？** 主线判定是历史统计规则下的状态划分，天然存在证伪概率（萌芽期多数最终证伪）。给出阶段与风险提示，让判断留在使用者手上，是刻意选择而非功能缺失。

**量能倍数为什么改了口径？** 原口径「近 5 日均额 ÷ 近 20 日均额」的分母包含分子，比值会被近期自身水平拉动，同一阈值对不同板块不等价。现改为「近 5 日均额 ÷ 前 20 日（不含最近 5 日）均额」，界面同时给出新旧两套倍数供观察。
