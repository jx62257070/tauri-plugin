# 股票主线（dsh-mainline）

把「板块抱团主线」从主观感觉变成**状态判定**：左侧导航新增「股票主线」看板，
对同花顺行业板块计算成交占比分位 / 量能倍数 / 价格分位三项原始指标，映射到
**一线四阶段**（萌芽 → 确认 → 狂热 → 瓦解），并同时展示原始指标面板与对应的风险提示。

## 硬约束（界面已落实）

1. 只输出**阶段标签与风险提示**，不出现任何买卖 / 仓位指令；
2. 只有价格上涨、没有业绩验证**不判「确认抱团」**——「确认」仅代表量价与拥挤度
   特征，风险提示里明写「需连续两季业绩验证」；
3. 原始指标面板与自动标签**同时展示**，并列出本期未接入的输入（如缺 LIMIT-Up 池数据）。

## 数据来源

- 同花顺板块日 K（`d.10jqka.com.cn/v6/line/48_<code>/…`），含 `last.js` 近端文件回退；
- 东财板块清单（clist，`fid=f12` 按代码稳定排序分页，收完与 `total` 对账）；
- 沪深两市成交额、涨停池（走宿主 `app:market` 服务）。

## 安装后怎么用

1. 首次进入看板是一片空 —— 扫描属重接口，**只在你点击时触发**，不做自动轮询；
2. 点一次「扫描」后会全员抓板块日 K 并落插件表（`plugin_dsh-mainline_board_history` /
   `plugin_dsh-mainline_scan_meta`），之后再进页面**只读库重算，不联网**；
3. 想更新数据再点一次「重新扫描」即可。

## 数据存放

- 结构化数据走宿主 `ctx.db`，两张插件独立表；
- 卸载插件时宿主会询问是否一并删表；**插件 id 一个字都不能改**，改了就等于换了一张新表，
  历史扫描结果全部失联。
