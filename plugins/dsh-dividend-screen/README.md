# 股息筛选（dsh-dividend-screen）

安装包文件名：`dsh-dividend-screen-1.0.0.zip`

一句话：市面上多数股息排行是 TTM 口径（只反映「过去派了多少」），本插件在同一张表上叠加**今年推算** —— 以今年中报 ÷ 去年中报的净利比作全年增长系数、保留去年分红率，推出「维持分红习惯下的今年股息率」，并把**伪高股息**（高负债、现金流盖不住、增长失速）用规则筛出来。

## 功能特性

- **自算 TTM 股息率**：按**除权除息日**归集近 12 个月已实施派息 ÷ 现价，与同花顺「股息率(TTM)」同口径。
- **今年股息率推算**：以今年中报 ÷ 去年中报的净利比作全年增长系数、保留去年分红率，推算今年股息率并给出与去年的差值。
- **伪高股息规则筛选**：真高股息条件（全部满足才保留）+ 伪高股息剔除规则（命中任一即剔除），支持自定义规则组、恢复默认预置。
- **两个 tab + 行内明细**：顶部「股息筛选」「股息自选」两个 tab；点任意行展开可看分红史明细、推算输入与未通过的规则项。
- **表格列可配置**：13 个数据列可显隐与排序，改动对两个 tab 即时生效。
- **数据本地留存**：扫描结果落本地表，再进页面只读本地快照渲染、零联网。

## 安装

前置：已安装 **WHF 股票看板**。

1. 打开应用，进入「插件工坊」（应用内的插件管理入口）；
2. 选择「导入插件」，选中 `dsh-dividend-screen-1.0.0.zip`；
3. 导入后启用，左侧导航会出现「股息筛选」。

卸载：在「插件工坊」里对该插件点卸载，应用会询问是否一并删除本地数据表。

## 快速上手

1. 首次进入是空表 —— 点「扫描排行」才开始按 TTM 股息率拉取前 N 名并叠加中报推算；
2. 扫描完成后结果落本地表，之后再进页面**只读本地表渲染、零联网**；
3. 在「筛选」tab 用快捷筛选（仅已披露中报 / 仅净利增长 / 仅可推算）与规则组收窄名单，点行展开看推算明细；
4. 在「股息自选」tab 可把样本池外的自选股按需补进来（点击触发单股取数），也能一键把当前名单加入自选；
5. 样本池默认前 200，可在页内切换 100 / 200 / 300 / 500。

## 配置项

| 配置名 | 说明 | 默认值 | 修改位置 |
| --- | --- | --- | --- |
| 表格列配置 | 控制结果表格显示哪些列、按什么顺序；改动对两个 tab 即时生效 | 13 个数据列全部按默认顺序显示 | 应用顶栏齿轮 → 插件设置 → 表格列配置 |
| 规则组 | 筛选规则（须全部满足）+ 排除规则（命中任一即剔除）；改规则不触发网络请求 | 默认预置规则组 | 插件页面内的「筛选规则」面板 |

## 数据与隐私

- **数据来源**：东方财富 —— 股息率排行（`push2delay` clist）、业绩报表与分红明细、资产负债表（`datacenter-web`）；全部请求**串行**并留间隔（行情域 1 s / 数据中心 600 ms），原地小步重试兜底。
- **联网时机**：**只由你点击触发**（「扫描排行」或自选 tab 的个股搜索预览），不轮询。
- **本地存储**：结构化数据落在插件的四张本地数据表 —— `plugin_dsh_dividend_screen_screen_rows`（展示行快照）、`plugin_dsh_dividend_screen_scan_meta`（扫描元信息）、`plugin_dsh_dividend_screen_config`（自定义规则配置）、`plugin_dsh_dividend_screen_watchlist`（股息自选）。
- **卸载影响**：卸载时应用会询问是否一并删除这些表；**插件 id 一个字都不能改** —— 改了就等于换了一批新表，历史扫描结果全部失联。

## 已知限制

- **定位声明**：只给状态与风险标记，**不含任何买卖指令**；推算是线性外推，不是预告。
- **口径说明（为什么要自算）**：东财 `f133` 字段实测**并非近 12 个月** —— 它是最新年报期分红 ÷ 现价，一年多次分红的个股会被系统性低估（招商银行 2026-09 实测只算了末期）。因此 `f133` 只用于**选样本池**，界面展示的 TTM / 去年 / 推算股息率全部由插件自算。
- **跨平台口径差异**：集思录等第三方「静态股息率」按分红的**到账自然年**归集，本插件「去年股息率」按**财务报告期**归集，同一只股可差近一倍，对比前请先对齐口径。
- **推算失真场景**：分红率沿用去年，中报增速对全年为线性外推；季节性强的行业（白酒 / 工程等下半年占比高）与并购重组个股会显著失真。
- **按需拉取的时效**：自选 tab 里对样本池外个股的指标为点击时按需拉取，口径与扫描一致，但**不写入快照**，重进页面即消失。

## 设计说明

**为什么用中报增速外推全年？** 因为多数 A 股还没披露年报，中报是当下能拿到的最新、且带可比同期基数的财务数据点。选择「今年中报 ÷ 去年中报」作增长系数，是让推算有一个透明、可复现的输入。推算公式与全部输入在页面展开区**直接写出来**，不做黑箱打分。
