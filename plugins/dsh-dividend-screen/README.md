# 股息筛选（dsh-dividend-screen）

市面上的股息排行大多是 TTM 口径 —— 只反映「过去派了多少」。本插件在同一张表上
叠加**今年推算**：以今年中报 ÷ 去年中报的净利比作全年增长系数、保留去年分红率，
推出「维持分红习惯下的今年股息率」，并把**伪高股息**（高负债、现金流盖不住、
增长失速）用规则筛选出来。

## 三个 tab

1. **筛选**：样本池默认前 200（可调），展示自算 TTM 股息率、去年股息率、分红率、
   连续分红年数、推算股息率与推算差值，以及规则命中情况；支持表头显隐与排序、
   快捷筛选（已披露中报 / 净利增长 / 可推算 / 未通过）与自定义规则组；
2. **自选**：把样本池外的自选股按需补到本地展示（点击触发单股取数），支持就地加自选；
3. **详情**：点行展开，看这只票的分红史明细、推算输入与未通过的规则项。

## 口径说明（为什么要自算）

- 东财 `f133` 实测**并非近 12 个月**：它是最新年报期分红 ÷ 现价，一年多次分红的
  个股会被系统性低估（招商银行 2026-09 实测只算了末期)。本插件自算 TTM =
  近 12 个月内除权除息的每股派息合计 ÷ 现价，与同花顺「股息率(TTM)」同口径；
- 推算公式与输入在页面上**直接写出来**，不做黑箱打分；
- **没有买卖指令**，只给状态与风险标记。

## 数据来源与频率

- 东财 push2delay 排行 / ulist.np 行情 / datacenter 业绩 · 分红 · 负债表；
- 全部**串行**，同上游请求之间留间隔（行情域 1s / 数据中心 600ms）；东财会直接
  掐连接（`fetch failed`）→ 原地小步重试是唯一有效兜底；
- **只由用户点击触发**（扫描排行 / 搜索预览），不轮询。

## 安装后怎么用

1. 首次进入看板是空表 —— 点「扫描排行」才开始取数；
2. 扫描结果落插件表（`plugin_dsh-dividend-screen_screen_rows` 等），
   之后再进页面**只读库渲染、零联网**；
3. 表头显隐 / 顺序在**顶栏齿轮 → 插件设置 → 表格列配置**里改，即时生效。

## 数据存放

- 结构化数据走宿主 `ctx.db`，每张表都是本插件独立命名空间；
- 卸载插件时宿主会询问是否一并删表；**插件 id 一个字都不能改**，
  改了就等于换了一批新表，历史扫描结果全部失联。
