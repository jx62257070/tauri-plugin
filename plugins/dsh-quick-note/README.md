# 速记（dsh-quick-note）

安装包从 [GitHub Release](https://github.com/jx62257070/tauri-plugin/releases) 下载，文件名形如 `dsh-quick-note-<版本>.zip`（版本以 Release 页面为准）。

一句话：左侧栏底部多一个「速记」入口（抽屉形态），随手记一条、随写随存，还能关联一只股票 —— 关联过的速记会自动出现在**这只股票的个股详情**里。

## 功能特性

- **随写随存**：侧栏底部点「速记」打开右侧抽屉，写完点「保存」（或 `Ctrl + Enter` 保存），「保存并关闭」顺手收起抽屉。
- **关联一只股票**：编辑区下方点「关联股票」→ 弹出全站统一的标的搜索（含「上次搜索」），挑一只即可；标签上的 × 可清除关联。
- **点标签回看**：点速记上的关联标签，直接打开这只股票的详情侧栏。
- **在个股里就地记**：打开任意个股详情，底部扩展区「速记」里就地追加 —— 自动带上当前这只股票，不用再手选一遍。
- **对外可复用**：提供 `note:repo` 服务与 `note:saved` 事件，其他插件不互相 import 也能协作。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**。

1. 打开应用，进入「插件工坊」（应用内的插件管理入口）；
2. 选择「导入插件」，选中刚下载的 zip 安装包；
3. 导入后启用，左侧栏底部会出现「速记」入口。

卸载：在「插件工坊」里对该插件点卸载，应用会询问是否一并删除本地数据表。

## 快速上手

1. 第一次打开「速记」抽屉是一份空列表 —— 写点内容再保存即可。
2. 需要跟某只股票绑定时，点「关联股票」选一只，保存后这条速记就挂在该股上；
3. 打开任意个股详情，底部扩展区「速记」里能就地追加，并看到该股的全部关联速记；
4. 点速记上的关联标签可直接跳到那只股票的详情侧栏。

## 快捷键

| 快捷键 | 作用 | 范围 |
| --- | --- | --- |
| `Ctrl+Alt+N` | 打开速记抽屉 | 全局（经面板打开接口唤醒） |
| `Ctrl + Enter` | 保存当前速记 | 速记编辑区内 |

## 数据与隐私

- **联网**：不请求任何上游数据，纯本地记录。
- **本地存储**：速记落在插件的独立本地数据表 `plugin_dsh_quick_note_notes`（桌面端 SQLite / 浏览器端本地仿真），插件永不直接写 SQL。
- **数据迁移**：旧版本存在插件本地存储（`ctx.storage`）里的速记，会在**首次加载时自动迁移**进数据表，**只迁一次**；迁移后旧存储键即被清除，不再作为数据源。
- **卸载影响**：卸载时应用会询问是否一并删除数据表；**插件 id 一个字都不能改** —— 改了就等于换了一张新表，历史速记全部失联。

## 与其他插件的互操作

| 类型 | 名称 | 语义 | 谁在用 |
| --- | --- | --- | --- |
| 服务 | `note:repo` | 读写同一份速记（`list` / `listBySymbol` / `latest` / `create` / `remove`） | 其他插件 `ctx.consume('note:repo')` 即可复用 |
| 事件 | `note:saved` | 每新增一条速记广播一次，回传该条速记 | 其他插件可据此做聚合 / 提醒 |
| 命令 | 打开速记（`Ctrl+Alt+N`） | 经面板打开接口唤醒本插件的抽屉面板 | 全局快捷键 |

## 已知限制

- **正文长度上限**：单条速记超出上限会被截断，避免一条占满整个侧栏。
- **删除不可恢复**：删除一条速记后无法撤销。
- **数据迁移只做一次**：迁移以「数据表为空且旧存储有数据」为条件，只在首次加载时执行；之后旧存储键不再作为数据源。
- **id 稳定性**：插件 id 与数据表名绑定，改动会导致历史数据失联。
