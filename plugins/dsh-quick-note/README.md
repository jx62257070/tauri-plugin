# 速记（dsh-quick-note）

左侧栏底部多一个「速记」入口（抽屉形态）：随手记一条，随写随存（`Ctrl + Enter` 保存），
可以关联一只股票，关联过的速记会自动出现在**这只股票的个股详情**里。

## 用起来是什么样

1. **随手记**：侧栏底部点「速记」打开右侧抽屉，写完点「保存」（或 `Ctrl + Enter`），
   「保存并关闭」则顺手收起抽屉；
2. **关联股票**：编辑区下方点「关联股票」→ 弹出全站统一的标的搜索（含「上次搜索」），
   挑一只即可；标签上的 × 可以清除关联；
3. **回看**：点速记上的关联标签，直接打开这只股票的详情侧栏；
4. **在个股里记**：打开任意个股详情，底部扩展区「速记」里就地追加 ——
   自动带上当前这只股票，不用再手选一遍。

## 数据存放在哪

- 速记落在本插件独立表 `plugin_dsh_quick_note_notes`（宿主 `ctx.db`，
  Tauri 端 SQLite / 浏览器端本地仿真），**插件永不直接写 SQL**；
- 旧版本存在 `ctx.storage` 里的速记会在首次加载时**自动迁移**进数据表，只迁一次；
- 卸载插件时宿主会询问是否一并删表；**插件 id 一个字都不能改** ——
  改了就等于换了一张新表，历史速记全部失联。

## 对外提供什么（其他插件可以复用）

- 服务 `note:repo`：读写同一份速记（`list` / `listBySymbol` / `latest` / `create` / `remove`）；
- 事件 `note:saved`：每新增一条广播一次 —— 插件之间不互相 import 也能协作；
- 命令「打开速记」（`Ctrl+Alt+N`）：经宿主 `panel:open` 唤醒自己的抽屉面板。

## 依赖的宿主服务

`app:ui`（按钮 / 空态 / 图标）、`app:format`（相对时间、裸代码）、`app:stock-open`
（点关联标签开详情侧栏）、`app:stock-picker`（宿主渲染的选股弹窗）、`app:watchlist`
（自选股查名）、`app:quotes`（自选股里查不到名称时兜底取一次名称）、`panel:close`
（「保存并关闭」）。
